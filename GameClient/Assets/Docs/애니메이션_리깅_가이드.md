# Mixamo 애니메이션 공유 가이드

## 개요
Mixamo에서 애니메이션을 한 번만 받아서 여러 캐릭터에 공유하는 방법입니다.

---

## 1단계. 애니메이션 받기 (Without Skin)

대표 캐릭터로 필요한 애니메이션을 Without Skin으로 다운받습니다.

```
Mixamo → 대표 캐릭터 업로드
→ 원하는 애니메이션 선택
→ Download
→ Format: FBX
→ Skin: Without Skin
→ Keyframe Reduction: Non-Uniform
→ Use Symmetry: ✅ (좌우 대칭 리깅)
→ Skeleton LOD: No Fingers (탑다운 모바일, 손가락 불필요)
→ Download
```

필요한 애니메이션 목록 예시:
- Idle.fbx
- Walk.fbx
- Attack.fbx
- Hit.fbx
- Die.fbx

---

## 2단계. 대표 캐릭터 Avatar 생성

```
Mixamo → 대표 캐릭터 업로드
→ T-Pose 선택
→ Download
→ Format: FBX
→ Skin: With Skin
→ Use Symmetry: ✅
→ Skeleton LOD: No Fingers
→ Download
```

유니티에서:
```
대표 캐릭터 FBX 선택
→ Inspector → Rig 탭
→ Animation Type: Humanoid
→ Avatar Definition: Create From This Model
→ Strip Bones: ❌ (모델 FBX는 반드시 끄기)
→ Apply
```

---

## 3단계. 애니메이션 FBX Avatar 연결

Without Skin으로 받은 애니메이션 FBX들에 Avatar를 연결합니다.

```
Idle.fbx 선택 → Inspector → Rig 탭
→ Animation Type: Humanoid
→ Avatar Definition: Copy From Other Avatar
→ Source: 2단계에서 만든 Avatar 연결
→ Strip Bones: ❌
→ Apply

→ Animation 탭
→ Strip Bones: ✅ (애니메이션 FBX는 켜기)
→ Apply
```

나머지 애니메이션 FBX도 동일하게 반복합니다.

---

## 4단계. Animator Controller 생성

```
Project → Create → Animator Controller
→ 이름: CharacterAnimator

Animator Controller 열기
→ 각 애니메이션 FBX 안의 클립 드래그

파라미터 추가:
→ isWalking (Bool)
→ attack (Trigger)
→ hit (Trigger)
→ die (Trigger)

트랜지션 연결:
→ Idle → Walk: isWalking = true
→ Walk → Idle: isWalking = false
→ Any State → Attack: attack
→ Any State → Hit: hit
→ Any State → Die: die
```

---

## 5단계. 다른 캐릭터에 적용

새로운 캐릭터마다 아래 과정을 반복합니다.

```
Mixamo → 새 캐릭터 업로드
→ T-Pose 선택
→ With Skin으로 다운로드

유니티에서:
→ FBX 선택 → Rig → Humanoid
→ Avatar Definition: Create From This Model
→ Apply

→ Animator 컴포넌트
→ Controller: 4단계에서 만든 CharacterAnimator 연결
→ Apply Root Motion: ❌ 끄기
```

---

## 주의사항

- 모델은 항상 **Create From This Model**로 Avatar 생성
- 애니메이션 FBX는 **Copy From Other Avatar**로 Avatar 연결
- Avatar는 모델마다 따로 생성, 애니메이션 클립만 공유
- 체형이 많이 다르면 애니메이션이 어색하게 보일 수 있음
