* 스킬 태그
- 생성 방식 : 투사체, 낙하, 소환
- 이동 방식 : 직진, 유도, 튕김, 회전, 정지
- 충돌 방식 : 기본, 폭발, 연쇄
- 종류 : 물리, 마법
- 속성 : 기본, 화염, 빙결, 전격


* 패시브
- 공격력 증가
 ㄴ 전체 태그
 ㄴ 투사체만 (전체 보다 조금 더)
 ㄴ 속성 증가 (물리, 화염 등 전체보다 조금 더)
- 체력 증가
- 공격 속도 증가 (기본 공격)
- 획득 범위 증가


- 마법+화염 폭발 효과 부여
- 투사체 거리 증가


* 검기
- 크기 커짐
- 더 멀리
- 더 짧게 위력 증가

- 여러 개
- 여러 방향


* 화염구
- 폭발해 스플래시 데미지
- 여러 방향으로 발사 (2갈래->3갈래->5갈래)
- 유도 or 관통 (하나만)


* 고드름
- 관통



* 상태 이상
- 열상 : 지속 데미지
- 동상 : 이속 느려짐
